LEGION privacy

LEGION is a personal assistant that one household runs for itself. It is not a commercial product, it has no customers, and it shows no ads. This page says what it does with your data, including data from your Google account.

Who runs it

Each household runs its own copy of LEGION on a server it controls. The copy this page belongs to is run by Kevin Win for his own household. Nobody else operates it, and no data goes to the project's author for any other household.

What it stores, and where

  • Records you create or import (calendar items, coursework, lists, money, food, car and health logs, notes, and recordings you start yourself) are stored in the household's own database.
  • Logins you hand to the server with tools/connect_session.py are stored encrypted. Nobody can read them back through the app, the owner included. Passwords are never asked for or stored. A bank session is never stored at all.
  • Mail other people send you is read to answer a question and then dropped. It is never stored.

Google user data

If you connect Google Drive, LEGION asks for two permissions, and uses them only as follows:

  • See and download your Drive files (drive.readonly): reads the bank statements you put in the one folder you choose, so they can be added to your ledger.
  • Create and manage files this app makes (drive.file): writes nightly database backups to a LEGION backups folder in your Drive, and removes the old backups it made itself. It never touches files it did not create.

Bank statements may be sent to Google's Gemini model under the household's own API key, to read line items that no parser recognises. Every figure must then add up to the totals printed on the statement, or the statement is rejected.

Limited use. LEGION's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only for the features above. It is not sold, not used for advertising, not shared with anyone outside the household, and never used to train AI models.

Who else handles it

The household's server runs on Google Cloud Run, and its database is hosted by Supabase. Backups go to your own Google Drive. None of them is given the data for any purpose of its own.

Removing it

  • Revoke Drive access at any time at myaccount.google.com/permissions. The next scheduled job then reports that it needs you to log in again, and does nothing else.
  • Deleting the LEGION backups folder removes every backup.
  • The household owner can delete any record, or the whole database.
