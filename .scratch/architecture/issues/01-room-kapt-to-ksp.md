# Room moves from kapt to KSP

First, so Hilt does not add a second annotation processor on top of one that should already be gone.
Room 2.8 supports KSP. `exportSchema` stays on; the generated schema JSON under `app/schemas/` must
be byte-identical before and after (kapt and KSP generate the same SQL for the same entities, and
`CarDatabaseSchemaVersionTest` plus every `MigrationNNToMMTest` diff against the live JSON, so a
drift shows as red). The KDoc `\uXXXX` escape that broke kapt on 2026-09-01 is irrelevant under KSP;
leave the reworded comments alone anyway.

Verify: `compileDebugKotlin -Pnokey`, full suite from the JUnit XML, `git diff --stat app/schemas`
empty, and measure clean-build time before and after, recorded in this ticket.

## Measured (2026-09-05)

KSP version: `2.2.10-2.0.2`, matching the Kotlin compiler this repo actually runs (root
`build.gradle.kts` pins `org.jetbrains.kotlin.android`/`plugin.compose` to 2.2.10 directly - the
`kotlin = "2.1.0"` ref in `gradle/libs.versions.toml` is stale for that pair and is only still read
by the `kotlin-serialization` plugin alias). Confirmed against the Gradle Plugin Portal's own
`maven-metadata.xml` for `com.google.devtools.ksp`, not guessed - 2.2.10 has exactly one published
KSP release.

`kapt(...)` had exactly one user in `app/build.gradle.kts` (`libs.room.compiler`), so the
`kotlin-kapt` plugin itself is removed, not just Room's use of it. `room.schemaLocation` moved from
the `kapt { arguments { } }` block to `ksp { arg(...) }` verbatim - Room 2.8's documented KSP path,
same output directory (`app/schemas`), `exportSchema` untouched.

|---|---|
| Before (kapt) | 3m 15s (196s wall) |
| After (KSP) | 2m 41s (162s wall) |

`git diff --stat app/schemas` after the KSP build: **empty**. kapt and KSP generated byte-identical
schema JSON.

`testDebugUnitTest -Pnokey`: BUILD SUCCESSFUL. Totals read from the JUnit XML under
`app/build/test-results/` (summed `tests`/`failures`/`errors`/`skipped` attributes across every

the ticket's stated baseline.

No entity, DAO, migration, Hilt or detekt file touched. Files changed: root `build.gradle.kts`,
`app/build.gradle.kts`, `gradle/libs.versions.toml`.
