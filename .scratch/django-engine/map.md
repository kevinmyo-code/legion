# Django is the engine: one server, a native Android limb, a web limb

**Kevin, 2026-09-05**, after the architecture meeting: *"im thinking we copy instagram right, django
with 2 native apps reading it"* and, to the shape below, *"yeah i think thats the way to go."*
Ruling: `docs/adr/0044-django-is-the-engine.md`. Log: `memory/library/decisions.md` 2026-09-05.

## The shape

```
Postgres            one container. Django owns its schema. Integrity triggers stay in SQL.
Django (server/)    the engine. REST API, the section 4 gate, auth, media, the worker. The ONLY writer.
Android app         device limb. Voice, OBD, wake word, Room replica. Talks HTTPS JSON to Django.
Web app (PWA)       the second adult's limb, on an iPhone and a desk. Django templates + HTMX.
Robot, later        device limb. Same API, same token scheme.
```

| Piece | Owns | Does not |
|---|---|---|
| Django | schema, migrations, every rule, every write | run on a phone |
| Android | device hardware, the Room replica as a read cache | write to Postgres directly |
| Web app | screens | hold its own data |
| Supabase | nothing, after ticket 10 | exist |

## Rules that survive unchanged, said so nobody relitigates them

- Section 4, all eight rules. The gate moves language, not posture. Ticket 03's acceptance test is
  the existing gate corpus producing identical outcomes.
- Money is `Long` cents. In Python: `int`, never `float`, never `Decimal` for cents.
- Provenance tags. `forbid_mutation_of_facts` stays a trigger, shipped by a Django migration.
- Two adults, no roles, no tenancy. One household per server.
- Third-party content read-through only. Nothing new here.
- Every voice capability has a hands path. The web app IS a hands path for her.
- Clone-and-run, restated: clone, `docker compose up`, make two users, point the app at the URL.

## Who works where

Two agents, one checkout, two disjoint surfaces:

| Surface | Agent | Paths |
|---|---|---|
| Server, web app, deploy | this terminal | `server/`, `deploy/`, this map |
| Android | the other terminal | `app/` via the `architecture` map, then ticket 09 here |

Rule from memory: **one Gradle writer at a time.** The server terminal never runs Gradle. The
handoff artefact between the two is the OpenAPI schema `server/openapi.yaml`, regenerated by
`manage.py spectacular`, committed. Ticket 09 codes against it, not against a conversation.
