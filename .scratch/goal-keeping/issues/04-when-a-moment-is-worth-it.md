# What makes a moment worth interrupting

Type: grilling
Status: open
Blocked by: 01, 03

## Question

The heart of the map. Everything else decides what is true about a goal; this decides when saying it
out loud helps rather than annoys.

The existing 11 unprompted lines all trigger on a physical event - ignition, a code, a temperature,
an arrival. A goal has no event. "You are behind on the deck" is true continuously, which means the
trigger has to come from somewhere other than the fact itself.

Decide:

1. **What supplies the moment.** Time of day, a state CHANGE (crossed from on-track to off), a
   natural boundary (start of a drive, end of a week), or Kevin's own declared cadence from ticket 02.
2. **Change versus state.** Speaking on a change is self-limiting and quiet; speaking on a state
   repeats until fixed, which is where nagging comes from. Kevin's own example - "it's past 10pm,
   perhaps rest is in order" - is a STATE, and it is the one he asked for, so a pure change rule
   contradicts the brief.
3. **Where the rule is evaluated**, given the app is only alive when the foreground service is
   running and `.scratch/proactive-mode/issues/07-scheduling-research.md` found that Samsung's
   sleeping-apps layer can drop an unused-UI app to one alarm per day while everything looks fine.
   A keeper that only speaks while driving is a car feature again.
4. **Does a raise carry its reason?** `.scratch/proactive-mode/issues/02-trigger-engine.md` item 4
   asks the same question for its own engine. If Alfred says it, can he answer "why did you say
   that" with the actual trigger. Decide it once, here, and let that map consume it.
5. **The compulsion line.** `.scratch/proactive-mode/issues/03-compulsion-test.md` owns writing it as
   a runnable test. This ticket owes that one a definition it can test: what distinguishes a nudge
   that serves Kevin from one engineered to produce engagement, stated concretely enough to fail a
   build.
6. **Cost.** If any part of the decision runs a model, what a tick costs on Kevin's own key and how
   often it ticks.
