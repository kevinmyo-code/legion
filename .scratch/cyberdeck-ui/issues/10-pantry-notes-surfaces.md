# Pantry + Notes/Agenda/Lists surfaces

Type: grilling
Status: resolved
Blocked by: 01

## Question

The lighter-touch surfaces. Pantry: receipts + line items + macro estimates - does it get any viz
(grocery spend trend? macro density?) or just the deck treatment on its lists. Notes/Agenda/Lists:
calendar and reminders inside the deck fiction - agenda as mission log? - without making a todo
list harder to use than a plain one. Decide how far each goes; "inherit the panels, skip the
charts" is an acceptable answer where data is thin.

## Answer

Resolved 2026-08-08 by delegation (Kevin: "resolve them all with ur default recs").

1. **Pantry: inherit the panels, skip the charts.** Deck-skinned receipt + line-item lists, an
   OPS-style status row for ingest state (reconciled / quarantined counts), macro estimates
   worded `EST` per the semantic ticket. No bespoke Pantry charts - grocery spend already rides
   in CRED's FLOW panel; a second chart of the same money would be double-counting by another
   name. Stays reachable where it lives today (under the money route).
2. **LOG module (Notes/Agenda/Lists): usability beats fiction.** Agenda renders as a mission-log
   day timeline (timed items on a rail, all-day items above it) - deck-skinned, zero charts.
   Lists stay lists; recurrence, skip, and edit flows re-skinned, not re-designed. A todo list
   that got harder to use would be the overhaul failing its own brief.
